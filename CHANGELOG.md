# Changelog

## v0.1.3

- Show the main window before initializing WebView2 or fetching feeds so first launch is not hidden behind startup work.
- Display startup failures and write exception details to `%LOCALAPPDATA%\LocalNewsReader\startup.log`.
- Keep the UI responsive if initial feed refresh encounters unexpected errors.

## v0.1.2

- Expanded first-run feed choices to 34 Japanese and international sources across general news, business, politics, technology, science, health, arts, sports, travel, and other sections.
- Expanded interest presets and default classification categories to cover broad everyday news topics.
- Made category views include articles classified into descendant categories.
- Updated the product title, repository URL, and clone, commit, push, and release instructions for `RSS-Reader-Lite`.
- Published as a Windows x64 application targeting .NET Framework 4.8.
